## Upload feature (added 15:55 ET)
`genesleuth.data.api.build_case_from_upload(vcf_path: str, referral_pdf_path: str, sample_id: str | None = None) -> tuple[Case, dict]`
- No CaseTruth (nothing hidden, Reveal does not apply). Never raises.
- info = {"mode": "uploaded" | "fallback", "reason": str, "funnel": dict, "seconds": float, "n_suspects": int}
- uploaded: suspects from A1's `genesleuth.data.upload.suspects_from_vcf(vcf_path, sample, budget_s=30.0)` (imported lazily); case_id = "up-" + 12 hex of sha1(VCF bytes + PDF bytes); referral_pdf = copy at DATA_DIR/work/uploads/<case_id>/referral.pdf; funnel = A1's funnel + suspects count.
- fallback: invalid files (PDF must start with %PDF, be readable, < 15 MB; VCF non-empty, < 200 MB), UploadError, > 45 s total, zero suspects, A1 module missing, any other error -> prepared demo case from build_case(None, ...), reason = the real error text. UI text: "Using a prepared demo genome because: <reason>". The uploaded PDF is not used in fallback mode.
- Tests: tests/test_upload_case.py (11 pass; stand-in upload module injected).
