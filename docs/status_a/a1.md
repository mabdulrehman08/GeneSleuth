## VCF upload (genesleuth/data/upload.py), added 15:55 ET
- `suspects_from_vcf(vcf_path: str, sample: str | None = None, budget_s: float = 30.0) -> dict` with keys `sample_id`, `af_threshold` (0.01), `funnel` (ints), `suspects` (list[Variant], same `annotate_many` path as NA12878), `frequencies`, plus `assembly`, `notes` (list of human-readable caveats), `timings`. Raises `upload.UploadError` (plain Exception) with a readable message; nothing is faked.
- Accepts .vcf / .vcf.gz (magic-byte detected), first sample column unless `sample` is given; keeps 0/1, 1/1, 0|1, 1|0, 1|1 SNVs and indels <= 10 bp inside the 58 panel regions (multi-allelic split). Rejects: not a VCF (BCF etc.), sites-only files (no genotype column), unknown sample, GRCh37/hg19 (header ##reference or contig lengths) with "GRCh37 not supported", no usable variants in the panel, too large to parse within the budget. If the header has no ##reference/##contig info it is accepted and `assembly` says "GRCh38 (unverified ...)".
- AF order: VCF INFO gnomAD_AF/AF_popmax/... (plain INFO/AF is deliberately ignored), then assets/suspects_NA12878 gnomAD table (match by variant id), then gnomAD v4.1 streamed within the remaining budget (most informative variants first), else AF unknown -> `funnel["af_unknown"]`, kept as candidates (not assumed rare). Threshold AF < 0.01, cap 300: non-intron first, known-rare before AF-unknown, then introns closest to an exon boundary. `funnel` also has af_from_vcf / af_from_assets / af_from_gnomad_stream.
- Timing, real HG00096 test file (13,658 records cut to the panel regions, `DATA_DIR/work/test_upload_HG00096.vcf.gz`, not committed; built by probes/A/make_test_vcf.py): 26.5 s wall at budget_s=30 (parse 1 s). 8,304 of 13,516 panel variants got gnomAD AF from the assets table, 100 from the live stream, 5,112 stayed AF-unknown (the streaming mostly cannot finish in 30 s: gnomAD seeks are about 10+ s each batch); 300 suspects after the cap. A VCF from another individual therefore mostly gets frequencies for common variants only; rare ones stay "unknown". Raise budget_s for better coverage (a full stream took ~150 s for NA12878).
