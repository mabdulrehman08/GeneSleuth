# Submission checklist

## Before the 4:15 p.m. ET code freeze

- [ ] Push both sides' code, docs and small benchmark artifacts. Confirm the intended branch is current.
- [ ] Verify the README names what was built on Nov 21, 2026, and attributes the pre-event research briefs separately.
- [ ] Run three judge-style cases, including Random. Check the picker, PDF, live events, ranking, reveal, plot, and human review. Record build and investigation times.
- [ ] Confirm the benchmark uses the published held-out results and describes misses and incomplete arms.
- [ ] Verify `.env` is ignored and untracked. Check that public files contain no keys or local data.

## Submit by 5:00 p.m. ET on Nov 21

- [ ] Verify the repository is public from a logged-out browser.
- [ ] Record and upload the 60-second video. Check that the link opens when logged out.
- [ ] Add both team members and submit manually. [Hackathon submission page](https://cerebralvalley.ai/e/gemini-4-nyc/hackathon/submit)
- [ ] Confirm the submission in the event site.

## Before judging

- [ ] Run `python -m scripts.demo_check` with the live credentials and data bundle.
- [ ] Charge the laptop, test the projector and PDF display, and keep a phone hotspot ready.
- [ ] Keep a real run recording available locally. Label it “recorded run” if venue connectivity prevents the live demo.
- [ ] Rehearse three minutes of demo and two minutes of Q&A.
