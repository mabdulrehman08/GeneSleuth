Find the hidden variant.

A public disease variant is planted in a real genome. The investigator sees only the referral letter and the filtered candidate list. The answer stays on the server until you reveal it.

Or bring your own case

Upload a patient variant file (VCF, GRCh38, .vcf or .vcf.gz) and the referral letter (PDF, scanned or typed). If the files cannot be used, the page says so and uses a prepared demo genome instead.

Loading cases

  1. A genome is about three billion letters.

  2. A disease variant is one letter changed.

  3. Some changes only matter in one organ. A blood test can look right at the letter and see nothing.

GeneSleuth reads the doctor's letter, narrows three billion letters to a few hundred suspects, and asks AlphaGenome what each one does in the right tissue.
